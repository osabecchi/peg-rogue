# 潮珠 SHIODAMA

真珠の玉をサンゴのピンに当てて、深海の魔物と戦う物理ボール・ローグライト。

- 遊ぶ: https://osabecchi.github.io/peg-rogue/ (スマホはホーム画面に追加すると全画面・オフラインで遊べる)
- ビルド不要。`index.html` をそのまま開くか、http サーバーで配信する

## 遊び方

- 盤面をドラッグ(マウスなら動かす)して狙い、離す(クリック)と発射
- 当てたピンの数 × 玉のダメージが攻撃になる。オレンジの「会」は会心ピン、黒い機雷は2回当てると爆発
- 敵の頭上のマークは次の行動の予告。倒しきれないと近づいて攻撃してくる
- キーボード: ← → で狙い、スペースで発射・早送り、S で玉の交換、F で速さ、Esc でメニュー
- ゲームパッド: 左スティックで狙い、A で発射、X で交換、Y で速さ、START でメニュー

## 中身

- 3つの海域 + 深淵の主。各海域は分かれ道の地図(戦闘・強敵・できごと・店・宝箱・潮だまり)とボス
- 玉34種(+進化7種・呪い2種)、遺物80種、敵28種、ボス7体、潜り手4人
- 周回: 真珠で永久強化・潜り手・新しい装備を解放。水圧(難易度)20段階、エンドレス、デイリー、実績26個、図鑑、記録

## ファイル

| ファイル | 役割 |
|---|---|
| `js/data.js` | 数値とコンテンツ(調整はここだけ) |

| `js/game.js` | ゲームの決まり(画面なしでも動く) |
| `js/render.js` | Canvas の描画と演出 |
| `js/ui.js` | メニュー画面 |
| `js/audio.js` | 効果音と BGM の合成 |
| `js/main.js` | 起動・入力・毎フレームの処理 |
